## 📝 v0.0.23 Changelog

### 🏞️ Procedural Voxel Island Generator
* **Runtime Perlin Noise Terrain**:
  - Ground terrain is no longer a static workspace baseplate. It is generated dynamically at server boot (`math.noise`) into a floating grassy/dirt voxel island with natural rolling hills.
* **100% Destructible Voxel Blocks**:
  - The entire island terrain is built using identical 2x2x2 stud voxel blocks (`GrassBlock1x1` top layer, `DirtBlock1x1` sub-layer, `StoneCube1x1` core).
  - Enables minion NPCs and players to dig down into the ground, mine dirt/clay/stone, carve underground tunnels, and terraform castle foundations.
