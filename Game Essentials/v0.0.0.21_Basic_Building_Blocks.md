## 📝 v0.0.0.21 Changelog

### 🧱 Building Blocks Library Overhaul
* **Categorized Shapes & Dimensions**:
  - `1x1 Cube`: Standard 2x2x2 stud block.
  - `1x2 Beam / Wall`: Extended 2x4x2 stud beam.
  - `2x2 Slab / Floor`: Large 4x2x4 stud foundation slab.
  - `Stairs`: Inclined 2x2x2 stud ramp (`WedgePart`).
  - `Half-Wall`: Compact 2x1x2 stud cover wall.
  - `Pillar`: Vertical 2x4x2 stud structural column.
* **Expanded Materials**:
  - 🪵 **Ohio Wood** (Wood timber)
  - 🪨 **Gyatt Granite** (Cobblestone & Granite)
  - 🧱 **Skibidi Clay** (Red brick masonry)
  - 🏗️ **Sigma Concrete** (Smooth structural concrete)
  - ⚡ **Rizzite Shield** (Glowing cyan neon energy)

### 🖥️ UI & Engine Upgrades
* **Top Navigation Menu**: Updated `Blocks` tab with intuitive shape & material icons, cost descriptions, and category organization.
* **Placement & Building Engine**: Server `BuildingService` and client `PlacementController` now dynamically support `WedgePart` stairs and custom dimensional block bounds.
* **Master Game Document**: Created [MAIN_GAME_OVERVIEW.md](file:///c:/Users/gamin/Downloads/Roblox/Game%20Essentials/MAIN_GAME_OVERVIEW.md) as the living single source of truth for version `v0.0.0.21`.
