## 📝 v0.0.22 Changelog

### 📐 Visual Blueprint Voxel Grid Overlay
* **Visual Non-Colliding Grid Projection**:
  - When Build Mode is activated (pressing `B` or selecting a block from the top menu), a 3D visual blueprint voxel grid plane projects dynamically onto the ground/surface around the building cursor.
  - Purely visual (`CanCollide = false`, `CanQuery = false`, `CanTouch = false`, `Transparency = 0.5`).
  - Automatically hides when exiting Build Mode.
* **Blueprint Hologram Ghost**:
  - Ghost preview blocks render as glowing cyan blueprint holograms (`Color3.fromRGB(0, 190, 255)`, `Material = Enum.Material.ForceField`, `Transparency = 0.35`) with soft bevels to emphasize blueprint planning.
