## 📝 v0.0.2 Changelog

### 📐 Voxel Grid Rescaling
* **Rescaled Grid Unit**: Reduced `GameConfig.GRID_SIZE` from `4 studs` to **`2 studs`** (`2x2x2` studs per block).
* **Relative NPC Scale**: 
  - Standard Roblox character height: **5.0 – 5.5 studs**.
  - **1 Voxel Block (2 studs high)** = **~1/3 of an NPC height**.
  - **3 Stacked Voxel Blocks (6 studs high)** = **~1 full NPC height**.
* **Impact**: Allows far higher architectural detail for castles (half-walls, narrow arrow slits, battlement crenellations, staircases, and precision minion brick-by-brick building).

### ⚖️ Balance & Cost Adjustments
* Reduced block material costs to match smaller block size:
  - **Wood Block**: 2 Ohio Wood (was 5).
  - **Stone Block**: 3 Gyatt Granite (was 8).
  - **Rizzite Shield Block**: 4 Gyatt Granite + 2 Rizzite Alloy.
* Adjusted individual block HP scaling for granular destruction.

### 🖥️ Top Screen Navigation Menu UI
* **Glassmorphism Design**: Centered top navigation bar (`BackgroundTransparency = 0.35`) with subtle glowing `UIStroke` border outline to stand out clearly on screen.
* **Category Tabs**:
  - 🧱 **Blocks**: Wood, Stone, Rizzite Shield, Spike Trap.
  - 🏰 **Buildings**: Archer Post, Storage Chest, Catapult Workshop, Iron Portcullis.
  - 👕 **Clothes / Skins**: Gigachad Outfit, Rizz Streamer Drip, Purple Grimace, Pure Gold Armor.
  - ⚔️ **Weapons**: Rizz Blade, Fanum Tax Bow, Ohio Battleaxe, Kamikaze Bomb.
  - 📜 **Tasks**: Harvest Ohio Wood, Mine Gyatt Granite, Auto-Build Castle, Patrol Base.
  - 🛒 **Shop / Drip**: Blueprint Slots, Neon HUD Theme, Mewing SFX Pack, Mini Sigma Pet.
* **Collapsible Sub-Drawer Panel**: Animated dropdown panel displaying item cards when clicking any category tab. Selecting a block switches active grid placement mode directly.
