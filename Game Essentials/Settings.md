## 🎮 1. Available Game Modes

| Game Mode | Mode Description | Resource Rules | Combat Rules |
| :--- | :--- | :--- | :--- |
| **Survival ("Longest Run")** | Standard day/night cycle base defense. | Harvest required | Night enemy waves active |

## 🛠️ 2. Developer & Testing Cheats

| Cheat Option | Description | Default State |
| :--- | :--- | :--- |
| **Infinite Resources** | Bypasses all material crafting costs. | `OFF` (On in Creative) |
| **God Mode** | Player and Minions take 0 damage. | `OFF` |
| **Instant Building** | Minions complete builds instantly. | `OFF` |
| **Clear All Placed Blocks** | Clears all placed blocks in Workspace. | Action Button |

---

## 📐 3. Grid & Building Controls

| Setting Name | Options / Values | Description |
| :--- | :--- | :--- |
| **Smooth Grid Lerp** | `Enabled` / `Disabled` | Smoothly interpolates ghost placement box instead of instant jerky snapping. |
| **Ghost Mode (Noclip)** | `OFF` (Toggle ON in Settings) | Turns player into non-colliding noclip avatar to walk through placed structures freely during testing. |
| **Grid Snap Resolution** | `2 studs` | Standard 1/3 NPC scale voxel snap unit. |
| **Ghost Visibility** | `40% Transparency` | Semi-transparent preview box. |
