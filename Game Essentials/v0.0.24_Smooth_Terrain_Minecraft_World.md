## 📝 v0.0.24 Changelog

### 🏞️ Roblox Smooth Terrain Minecraft World
* **Native C++ Voxel Engine (`Workspace.Terrain`)**:
  - Replaced loose part instances with Roblox native Smooth Terrain for maximum performance and 60 FPS gameplay.
  - Generates a vast 128x128 stud Minecraft-style island with organic rolling hills, lush grass surfaces (`Enum.Material.Grass`), rich soil sub-layers (`Enum.Material.Dirt`), and stone foundations (`Enum.Material.Rock`).
* **Terrain Digging & Mining API**:
  - Added `BuildingService.digTerrain(position, radius)` using `Workspace.Terrain:FillBall(position, radius, Enum.Material.Air)`.
  - Minion NPCs can dig holes, mine underground resources, and terraform castle moats natively!
