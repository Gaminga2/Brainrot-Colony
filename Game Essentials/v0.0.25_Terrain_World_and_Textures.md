## 📝 Combined Version Features & Changes (v0.0.23 - v0.0.25)

### 🏞️ 1. Roblox Smooth Terrain Minecraft World (2x Scale)
* **Native C++ Voxel Engine (`Workspace.Terrain`)**:
  - Replaced loose part instances with Roblox native C++ Smooth Terrain (`MinecraftWorldGenerator.luau`) for maximum 60 FPS performance.
  - Generates a vast 2x scale **320x320 stud** Minecraft-style island featuring lush grass surfaces (`Enum.Material.Grass`), rich soil sub-layers (`Enum.Material.Ground`), and rock foundation cores (`Enum.Material.Rock`).
* **Invisible Ghost Spawn Marker**:
  - Instantiates `IslandSpawnLocation` at `Vector3.new(0, surfaceY + 2, 0)` with `Transparency = 1` and `CanCollide = false`. Players spawn cleanly on grass without visible spawn plates.
* **Lethal Ocean Water Border**:
  - Surrounds the island with Smooth Terrain `Enum.Material.Water`. [LethalWaterService.luau](file:///c:/Users/gamin/Downloads/Roblox/src/server/Services/LethalWaterService.luau) monitors Workspace every 0.2s and instantly eliminates any player or minion that falls into the ocean (`Y <= 5`), forcing a clean respawn on the island!
* **Native Terrain Digging & Mining**:
  - Added `BuildingService.digTerrain(position, radius)` using `Workspace.Terrain:FillBall(..., Enum.Material.Air)`. Minion NPCs can dig holes, carve caves, and mine soil/stone natively!

### ⛰️ 2. 3x3 Surrounding Terrain Flattening Engine
* **3x3 Surrounding Neighborhood Clearing**:
  - Placing any block automatically carves out smooth terrain in a 3x3 voxel neighborhood (`FillBlock Air`), preventing terrain spikes, clipping corners, and grass sticking up through placed walls and floors.
  - Smooth rounded hill slopes in the 3x3 neighborhood under placed structures are automatically leveled and converted into clean, stepped 2-stud blocky voxel foundations (`GrassTopBlock1x1` / `DirtBlock1x1`).

### 🌾 3. Grass Blade Height & Foliage Control
* **Grass Height Setting**: Added a Grass Height setting row (`Off`, `Short`, `Medium`, `Tall`) under `Audio & Visuals` in [SettingsMenu.luau](file:///c:/Users/gamin/Downloads/Roblox/src/client/UI/SettingsMenu.luau) that controls `Workspace.Terrain.Decoration` and grass blade height.

### 🎨 4. Expanded Environmental Block Textures
* 🌿 **Grass Top Block (`GrassTopBlock1x1`)**: Top grass surface with dirt sides texture ([BlockVisuals.luau](file:///c:/Users/gamin/Downloads/Roblox/src/shared/Modules/BlockVisuals.luau)).
* 🪨 **Cobblestone 1x1 (`CobblestoneBlock1x1`)**: Heavy chiseled cobblestone masonry.
* 🧱 **Mossy Stone 1x1 (`MossyStoneBlock1x1`)**: Aged mossy ruin stone block.
* 🏜️ **Sandstone 1x1 (`SandstoneBlock1x1`)**: Smooth desert sandstone.

## 🐛 Errors Encountered & Fixes Applied

| Error Message / Symptom | Root Cause | Fix Applied | Affected Script(s) |
| :--- | :--- | :--- | :--- |
| `Dirt is not a valid member of "Enum.Material"` | Roblox `Enum.Material` uses `Ground` for earth/soil, not `Dirt`. | Replaced `Enum.Material.Dirt` with `Enum.Material.Ground`. | [GameConfig.luau](file:///c:/Users/gamin/Downloads/Roblox/src/shared/Modules/GameConfig.luau), [MinecraftWorldGenerator.luau](file:///c:/Users/gamin/Downloads/Roblox/src/server/Services/MinecraftWorldGenerator.luau) |
| `Expected identifier when parsing expression, got '}'` | Missing `Items = {` key in `Categories[1]` when adding new block entries. | Restored `Items = {` key in `Categories` table. | [TopNavigationMenu.luau](file:///c:/Users/gamin/Downloads/Roblox/src/client/UI/TopNavigationMenu.luau) |
| `The current thread cannot call 'GetDebugId' (lacking capability Plugin)` | `GetDebugId()` is a Plugin-level Roblox API unavailable in game runtime scripts. | Replaced `model:GetDebugId()` with `HttpService:GenerateGUID(false)`. | [MinionAIService.luau](file:///c:/Users/gamin/Downloads/Roblox/src/server/Services/MinionAIService.luau) |
